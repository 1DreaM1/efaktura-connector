# Security policy

## Reporting a vulnerability

Use GitHub's private vulnerability reporting form for this repository when it is available. Private reporting must be enabled in the repository settings. If GitHub does not offer the form, open an issue asking for a private contact channel; do not include vulnerability details in that public issue. See [GitHub's reporting guidance](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately).

Please include the affected package version or commit, PHP version, relevant component, impact, and a minimal reproduction using synthetic data. Do not send access tokens, client secrets, real invoices, personal data, or unredacted provider logs.

The maintainers will review reports and coordinate a fix and disclosure. This project does not promise a fixed response or remediation time.

## Scope

Report security issues affecting the connector's PHP package, optional Laravel bridge, bundled validation resources, or documented security-sensitive behavior. General usage questions and non-sensitive bugs belong in the public issue tracker.
