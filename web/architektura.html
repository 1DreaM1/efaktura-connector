Architektúra

Rozdelené zodpovednosti. Jasné integračné body.

Aplikačný kód závisí od kontraktov. Konkrétny transport a API poskytovateľa patria do infraštruktúry; možno ich nahradiť alebo oddeliť pri testovaní.

Návrh systému

Tri vrstvy, jeden smer závislostí.

01 · Rozhrania

Core

Stabilné rozhrania a typované vstupy a výstupy pre pracovný postup hostiteľa.

  • Odosielanie, doručená pošta, sledovanie, zistenie podpory
  • Konfigurácia a výnimky
  • Modely webhookov a validácie
02 · Hodnoty

Domain

Modely dokladov a účastníkov bez znalosti HTTP alebo Laravelu.

  • Účastník a stavy dokladov
  • Hodnoty UBL a návrhy dokladov
  • Limity a číselníky
03 · Implementácia

Infrastructure

Adaptéry poskytovateľa, koncové body, tokeny, transport a validačné nástroje.

  • SAPI + Peppol Gateway API
  • Opakovanie HTTP požiadaviek, istič obvodu, logovanie
  • UBL čítačka, zapisovač a validátory
Voliteľná integrácia

Laravel

Composer navrhuje illuminate/support v rozsahu 8.83–13. CI testuje bridge na Laravel 13 s PHP 8.4. Service provider zverejní konfiguráciu a sprístupní šifrovanú vyrovnávaciu pamäť tokenov aj koordináciu cez atomické zámky Laravel Cache. Jadro Laravel nevyžaduje; jeho PHP 7.4 kompatibilitu kontroluje hlavná testovacia matica. Metriky možno doplniť cez ConnectorMetricsInterface.

Možnosti použitia

Zapojte len tie časti, ktoré potrebujete.

Konektor môže obslúžiť celý technický tok dokladu alebo len lokálnu prácu s UBL. Integráciu si poskladáte podľa aplikácie.

01 · Laravel bridge

Aplikácia s kontajnerom služieb

Laravel service provider sprístupní predvolené API a UBL služby. Pri viacerých OAuth profiloch vyberte službu cez SapiClientRegistryInterface; pri povereniach v modeli zákazníka použite TenantEFakturaClientResolver. default_client určuje priame bindingy.

02 · Samostatné PHP

Integrácia bez frameworku

Používajte kontrakty Core a zostavte prenos ručne. Jadro nevyžaduje illuminate/support; stabilná ConnectorFactory zostaví klientov a cez withExecutorOptions(), withTokenRefreshLock(), withMetrics() a withClock() pridáte logovanie, koordináciu obnovy tokenu, metriky či vlastné hodiny.

03 · Viac účastníkov

Organizácie a rôzne firmy

Pri načítaní doručenej pošty získajte ID príjemcu aktuálnej organizácie a rovnaký objekt Participant použite pri zozname, stiahnutí aj potvrdení. Participant sa odovzdáva osobitne, nezávisle od vybraného OAuth profilu.

04 · Lokálne UBL

Nástroje bez volania API

Čítajte XML faktúry a dobropisu, zostavujte návrhy dokladov a spúšťajte lokálne kontroly bez sieťového volania. Java je potrebná iba pre Schematron.

05 · Testy hostiteľa

Offline klient bez poskytovateľa

FakeSapiClient a FakeDocumentSubmissionGateway z menného priestoru Testing nahrávajú odoslania, vracajú výsledky a zlyhania z fronty a pri rovnakom idempotency key vrátia pôvodný výsledok. Nepotrebujú poverenia ani sieť.

Vlastné fronty úloh, plánovač, databázu, obchodné schvaľovanie a HTTP koncový bod na prijímanie webhookov zabezpečuje hostiteľská aplikácia.
Repozitár

Kde čo patrí.

Modul oddeľuje verejné kontrakty, hodnoty a konkrétne integrácie. Nová logika poskytovateľa patrí do infraštruktúry, nie do doménových modelov.

src/Core/

Kontrakty a modely API

Rozhrania, konfigurácia, dátové objekty a typované chyby pre aplikačnú vrstvu.

src/Domain/

Hodnoty a pravidlá

Účastníci, stavy, doklady UBL, návrhy dokladov a číselníky bez závislostí od HTTP.

src/Infrastructure/

Adaptéry poskytovateľa a prostredia

Koncové body, OAuth, prenos, mapovanie API, čítanie a zápis XML aj validátory.

src/Testing/

Offline pomôcky pre testy

FakeSapiClient a FakeDocumentSubmissionGateway pre testy hostiteľskej aplikácie bez poskytovateľa.

integrations/laravel/

Voliteľná integrácia Laravelu

Väzby v Laraveli, poskytovateľ služieb a šifrovaná vyrovnávacia pamäť tokenov.

resources/validation/

Verziované podklady

UBL XSD, Schematron pravidlá, Saxon HE a licenčné oznámenia.

resources/code-lists/

Referenčné číselníky

Krajiny, ISO 4217 meny, UN/ECE jednotky, EAS a participant schémy aj 13 číselníkov Peppol Billing 2026-Q4-MR. Voliteľné aliasy jednotiek (ks, kg, hod) prevedie UnitCodeList::unit() na kódy UN/ECE.

tests/

Hranice a správanie

Jednotkové a integračné testy, testovací prenos a architektonické kontroly závislostí.

config/efaktura-connector.php

Predvolená konfigurácia

Predvolená konfigurácia Laravelu. Composer PSR-4 mapuje DreaM1\EfakturaConnector\ na src/; Laravel prefix smeruje do integrations/laravel/src/.

Podrobný strom a odporúčania na rozširovanie sú v dokumentácii štruktúry balíka ↗.
