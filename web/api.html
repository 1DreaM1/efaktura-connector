Tri rozhrania, typované výsledky.

Konektor implementuje API spoločnosti Datahosting podľa jej SAPI-SK API, Peppol Gateway API v1 a desiatich operácií samostatného Integrator API. Hostiteľská aplikácia nastavuje adresu prostredia.

Počty označujú implementované operácie vrstvy Infrastructure. OAuth token endpoint POST /sapi/auth/token používa konektor interne. Dávkové odoslanie POST /v1/send-documents prijíma najviac 100 dokumentov (každý do 10 MB; typ UBL_XML alebo SBDH_XML). Detail webhooku GET /v1/webhooks/{webhookId} je dostupný cez Core kontrakt WebhookRegistryInterface::get().
