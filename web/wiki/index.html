Konektor eFaktúr

Čítanie ≈ 2 min5 sekciíUpravené 27. 11. 2026

Frameworkovo nezávislá PHP knižnica na prácu s eFaktúrou spoločnosti datahosting.sk. Spája rozhrania SAPI-SK, Peppol Gateway a Integrator API, OAuth autentifikáciu, typované API služby, modely dokumentov a nástroje pre UBL 2.1.

Knižnica spracuje jednotlivé operácie. O tom, kedy doklad vytvoriť, overiť, odoslať alebo uložiť, rozhoduje hostiteľská aplikácia.

Rozhrania API¶[upraviť zdroj]

RozhraniePoužitie
SAPI-SKOAuth token, odoslanie cez SAPI, doručená pošta, stiahnutie a technické potvrdenie príjmu dokumentu.
Peppol GatewayDiscovery, validácia, profil participanta, stav odoslania, MLS a správa webhookov. Používa Bearer token získaný cez SAPI.
Integrator APISpráva OAuth klientov a participant prístupov, stránkovaný zoznam participantov, aktivácie, mesačné súhrny a PDS subject submission. Používa samostatné hlavičky Integrator API a PDS požiadaviek.

Základné pravidlá¶[upraviť zdroj]

  • SAPI potvrdzuje technické prijatie požiadavky; samo osebe nepotvrdzuje doručenie faktúry príjemcovi.
  • Čítanie UBL a jeho validácia sú samostatné operácie.
  • Knižnica neukladá dokumenty ani neurčuje workflow hostiteľskej aplikácie.
  • Výnimky obsahujú technické správy. Používateľské texty a preklady patria do hostiteľskej aplikácie.

API a technické podklady¶[upraviť zdroj]

Knižnica vychádza z testovacích SAPI-SK API špecifikácií a Peppol Gateway API v1. Testovací server prostredia nastavuje hostiteľská aplikácia v base_url.

Lokálny kombinovaný kontrakt API je v docs/eFaktura/api/openapi.json; testovacie OpenAPI zdroje sú dostupné pre SAPI-SK, Peppol Gateway v1 a Integrator API. Ďalšie podklady o SAPI-SK, Peppol Gateway a validačných artefaktoch nájdete v technickom prehľade eFaktúry.

Verzie validačných zdrojov a postup ich aktualizácie opisuje resources/validation/README.md.
